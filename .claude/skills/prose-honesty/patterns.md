# The 22 patterns

Read on a prose pass. A sibling file rather than part of `SKILL.md` because it
is a lookup table, not a procedure: an agent rewriting one sentence usually
needs two or three entries, not all twenty-two, and the entries it does not use
cost context for nothing.

Attribution: [blader/humanizer](https://github.com/blader/humanizer) (MIT),
which builds its pattern list on Wikipedia's *Signs of AI writing*.

**Staging instead of stating** — justify an edit on a single sighting.

1. **Not X but Y** — "it's not just a feature, it's a shift." State it.
2. **One-line closers** — "That is the real win." after every section. Cut the
   closer that only re-explains the example.
3. **Sayings that sound deep** — "At its core, what really matters is…"
   Replace with the specific claim.
4. **Staged run-up** — "Let's dive in", "Honestly? It depends." Remove and
   state the point.
5. **Arguing with no one** — "this isn't mainly about…", "a tempting approach
   would be…". Remove the objection nobody raised.

**Rhythm applied by rule** — a passage that shows three of these has a shape,
not a voice.

6. Forced triads — three examples plus a lesson, when the meaning needs two.
7. Repeated sentence openings.
8. Dashes as the universal connector.
9. Stacked qualifiers — "could potentially possibly be argued".
10. Passive voice where naming the actor is shorter.

**Inflation** — the three marked below are the shapes an unearned claim takes,
so they matter most in a repository whose north-star metric is false-proof
rate ≈ 0.

11. Overused vocabulary — delve, testament, landscape, showcasing.
12. **Inflated significance** — keep the fact, drop the significance, end on
    the last concrete fact.
13. Vague association — "associated with", "in connection with".
14. Shallow `-ing` riders — "symbolizing", "reflecting", "showcasing".
15. Sales language — "nestled within the breathtaking region".
16. **Borrowed authority** — "experts believe…", "cited in NYT, BBC, FT". Name a
    real source and what it said, or remove it.
17. Avoiding *is*, *are*, *has*.

**Formatting applied by rule** — invisible in a single sentence, obvious in a
page.

18. Bold as decoration.
19. Decorative headings — title case, emoji, arrows. Sentence case.
20. Chatbot residue — "Great question!", "I hope this helps!"
21. A heading repeated in the first sentence.
22. Writing about the document instead of its subject — "this function was
    added to replace…", "the table below compares…".
